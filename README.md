# GitHub Manager

Android-клиент для GitHub на Kotlin и Jetpack Compose: репозитории, исходный код с подсветкой,
Markdown, релизы и управление видимостью — без браузера и без собственного сервера.
Токен хранится в Android Keystore и уходит только в `api.github.com`.

## Возможности

**Репозитории**
- Вход по fine-grained personal access token; токен шифруется AES-GCM в Android Keystore.
- Список доступных токену репозиториев: поиск, фильтры «Все / Public / Private», подгрузка по 50.
- Карточки с владельцем, языком, датой последнего обновления и бейджем видимости.

**Код**
- Дерево файлов с навигацией вперёд/назад, в том числе системной кнопкой «Назад».
- Подсветка синтаксиса (Highlight.js локально в WebView, без сети) с выбором языка по расширению.
- Абсолютные номера строк с закреплённой колонкой при горизонтальной прокрутке.
- Постраничный вывод больших файлов (200 строк / ~24 КБ на страницу), копирование кода и пути, ссылка на GitHub.
- Картинки (PNG, JPEG, GIF, WebP, BMP) открываются в просмотрщике с пинч-зумом, панорамированием и двойным тапом для сброса; SVG рендерится тем же просмотрщиком.
- Двоичные файлы показывают размер и хекс-дамп первых 4 КБ (классический `xxd`-вид, 8 байт в строке на телефоне, 16 на широком экране) плюс ссылку на GitHub.
- Файлы до 2 МБ читаются через raw-эндпоинт GitHub, когда JSON-ответ обрезан; ограничение — 2 МБ на файл.

**Markdown**
- Файлы `.md`, `.markdown`, `.mdown` открываются отформатированным просмотром: заголовки, списки, таблицы, цитаты, блоки кода.
- Переключатель «Просмотр / Исходник» — исходник открывается тем же код-вьюером с подсветкой.

**Релизы**
- Список релизов: тег, дата, статусы draft/prerelease, раскрываемые release notes.
- Скачивание ассетов потоком с прогрессом и отменой; файл сохраняется через системный диалог (SAF), без разрешений на хранилище.
- Проверка размера и SHA-256, если GitHub отдаёт `sha256:`-дайджест; неполный файл удаляется.
- Токен отправляется только на `api.github.com`: запросы к CDN-редиректам идут без `Authorization`.

**Видимость репозитория**
- Переключение public/private с обязательным подтверждением полного имени репозитория.
- Перед изменением приложение заново проверяет права и состояние; кэш после мутации сбрасывается.

**Правка репозитория через GitHub API («Изменения»)**
- Переключение ветки: список веток репозитория, просмотр кода и коммиты идут в выбранной ветке (`?ref=`).
- Создание текстового файла и редактирование существующего во встроенном редакторе с минимальной подсветкой.
- Черновики шифруются AES-GCM в Android Keystore, привязаны к репозиторию и ветке, переживают перезапуск приложения;
  автосохранение редактора с задержкой 600 мс. Отдельного локального индекса Git нет.
- Переименование = создание нового пути + удаление старого в одном коммите; удаление файла — отдельное действие с подтверждением.
- Построчный предпросмотр diff (ограниченный LCS) для каждого черновика.
- Один атомарный коммит на несколько файлов через Git Data API; перед отправкой — подтверждение ветки.
- Защита от затирания: если файл изменился на GitHub (`sha` не совпадает) или создаётся поверх существующего,
  коммит отклоняется с сообщением, черновики сохраняются.

**Кэш и обновление**
- Все успешные GET кэшируются на диск в зашифрованном виде (AES-GCM, `noBackupFilesDir`), ключ включает хэш токена и URL.
- TTL 10 минут, затем условный запрос по `If-None-Match`/ETag (`304` продлевает TTL).
- Без сети разрешён fallback на устаревший кэш; ответы 401/403/404 и прочие ошибки API в кэш не подставляются.
- Кнопка ↻ всегда идёт в сеть мимо кэша, меню «Очистить кэш и обновить» чистит локальные данные.
- Пагинация по заголовку `Link: rel="next"` — полная последняя страница больше не показывает фантомную следующую.
- Источник данных виден в интерфейсе: сеть, `304`, свежий кэш или устаревший кэш без сети.
- Ответ 403 разбирается по `X-RateLimit-Remaining` / `X-RateLimit-Reset` / `Retry-After`: «нет прав» отличается от
  исчерпанного и вторичного лимита, в сообщении указано время следующей попытки. Автоматических повторов нет.
- Лимиты: 24 МБ / 250 записей, ответ больше 700 КБ не кэшируется.

**Прочее**
- Тёмная и светлая темы с переключением через меню; настройка сохраняется между запусками приложения.
- Поделиться ссылкой на репозиторий через системный share-sheet.

## Сборка

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Android Studio создаёт `local.properties` сама. Для сборки из консоли укажите SDK вручную
(`sdk.dir=G\:\\Android\\Sdk`) или задайте `ANDROID_HOME`.

Release-сборка (`:app:assembleRelease`) включает R8 и `shrinkResources`, но **не подписана**:
в проекте нет `signingConfig`, поэтому на устройство ставится debug-вариант.

## Токен

Создайте [fine-grained personal access token](https://github.com/settings/personal-access-tokens/new):

- **Contents: read** — просмотр кода и релизов, скачивание ассетов (включая приватные репозитории).
- **Contents: write** — только если нужны «Изменения»: создание, правка, переименование, удаление файлов и коммиты.
- **Administration: write** — только если действительно нужно менять видимость, и только на выбранных репозиториях.

Давайте минимальные права и короткий срок действия. Не публикуйте токен в issues, логах и скриншотах.

## Ограничения

- Нет OAuth Device Flow: нужен готовый PAT.
- Нет настоящего локального Git: `clone`/`stage`/`fetch`/`push`/`pull`/`merge`/`rebase` не реализованы,
  работа идёт через Contents/Git Data API GitHub. «Черновики» — это не индекс Git.
- Редактор упрощённый (Compose `BasicTextField` с regex-подсветкой), без Sora Editor и LSP.
- Предпросмотр ограничен 2 МБ на файл; у GIF/SVG показывается первый кадр/растр, без анимации. Докачки и фоновых загрузок нет.
- Подсветка внутри Markdown-блоков кода не включена — для этого есть режим «Исходник».
- Загруженные релизы/деревья живут в памяти сессии: список подгружается порциями по 50/30.
