# Матрица тестирования M0

| Сценарий | Ожидаемое поведение |
|---|---|
| Запуск без токена | Форма входа |
| Неверный токен | Ошибка 401, вход не сохраняется |
| Валидный токен с правом Metadata | Список доступных репозиториев, без управления при отсутствии admin |
| Токен только для части репозиториев | Видны только доступные токену репозитории |
| 50, 100, 101 репозиторий | Чёткое подгружение страниц, отсутствие дублей |
| Фильтр и поиск | Только загруженная выборка, поиск без регистра |
| Пустой репозиторий | Ошибка чтения содержимого не приводит к падению приложения |
| Бинарный или большой файл | Понятное сообщение, без декодирования большого blob |
| Fork, Archived, Internal | Опасная операция недоступна |
| Не-admin репозиторий | Изменение видимости недоступно |
| Смена состояния между экраном и подтверждением | Операция отменяется без PATCH |
| Ошибка PATCH | Нет повторной автоматической записи |
| PATCH успешный, GET проверки не работает | Сообщение «исход неизвестен», нужна ручная проверка |
| 403 policy restriction | Не обходится; отображается ошибка |
| Ротация экрана / background | State сохраняется в ViewModel, токен не передаётся через SavedState |
| Выход из аккаунта | Шифрованная копия токена удалена, навигация возвращена к login |
| Журнал запросов | Токен не попадает в логи |

## Правка репозитория через GitHub API (0.4 preview)

Автоматизировано (JVM): `RemotePoliciesTest` — безопасность путей, обязательный `originalSha` при удалении,
запрет дублирующихся путей, слияние черновиков, форма diff (включая новый/удалённый файл), «грязность» редактора.

| Сценарий | Ожидание |
|---|---|
| Создание файла в ветке | Один коммит с одним файлом, список обновляется |
| Переименование | Один коммит: удаление старого пути + создание нового |
| Создание поверх существующего файла | Коммит отклонён, черновики сохранены |
| Файл изменён на GitHub между чтением и коммитом | Коммит отклонён сообщением о конфликте `sha` |
| Back на неизменённом редакторе | Черновик не создаётся |
| Перезапуск приложения | Черновики и открытый редактор восстанавливаются |
| Выход из аккаунта | Черновики удалены |
| Ветка не по умолчанию | Чтение файлов и коммит идут в выбранную ветку |

**Автоматизированы на момент генерации:** только JVM unit tests для правил/смены видимости. Все UI и API сценарии требуют запуска на устройстве или эмуляторе.
